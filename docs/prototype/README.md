# KeyCase · 设计原型 v0.5

打开 `index.html` 即可（纯静态、无依赖、可离线）。这是**设计讨论用的原型**，不是最终 Android 实现。

## 包含的屏幕

- 解锁（垂直居中；默认指纹/主密码可设置）
- 首页（搜索 + 4 个统计块 + 最近使用 5 条）
- 密码列表（无分组标签，A–Z + 搜索）
- 密码详情（大图标、模糊密码、点击显示并复制）
- 编辑模式（右上角“编辑”→“保存”）
- 动态令牌列表（验证码 + 圆环秒数；可隐藏）
- 动态令牌详情（大码 + 细圆环）
- 手动添加令牌 / 扫码（模拟）
- 安全性（弱密码 / 常见密码 / 重复使用 + 规则开关）
- 最近删除（30 天、恢复、清空）
- 分组管理（新建 / 重命名 / 删除）
- 图标包（内置 Aegis Simple Icons，导入可删）
- 设置（分组、安全、默认解锁、令牌、备份、主题色、深色模式、图标包、导入）
- 搜索

## 可交互的点

- 底部四个标签切换：首页 / 密码 / 令牌 / 设置
- 首页 4 个统计块进入对应页面；“最近使用”打开条目
- 列表 A–Z 跳转、搜索
- 密码详情：点眼睛显示并复制；编辑 → 保存；删除进回收站
- 编辑条目时，顶部大图标右下角出现“换图标”按钮；没有图标或加载失败时用名称首字 + 背景色兜底
- 动态令牌：验证码每 30 秒变；**点验证码立即复制**；关掉“列表直接显示验证码”后，点 `••• •••` 会原地显示 10 秒并复制，宽度不变
- 设置 → 安全 → 默认解锁方式：指纹 / 主密码
- 设置 → 外观与图标 → 主题色：任意取色器 / 十六进制 / 5 个预设 / 恢复默认
- 设置 → 外观与图标 → 深色模式：跟随系统 / 浅色 / 深色
- 设置 → 整理 → 分组管理：新建、重命名、删除
- 设置 → 外观与图标 → 图标包：内置不可删，导入的可删
- 安全性：规则开关会实时影响列表
- 回收站：恢复 / 清空

## 假数据与图标

- 所有条目、验证码、备份时间均为假数据；验证码是本地哈希模拟的 6 位数字。
- `icons/` 是从 `assets/aegis-simple-icons-v269.zip` 里取的真实 SVG 图标（Simple Icons，CC0；品牌商标归各自所有者）。

## 文件

- `index.html` — 原型本体
- `icons/` — 原型用到的图标
- `*.png` — 各屏幕截图（1440×1000，含桌面展示框）
