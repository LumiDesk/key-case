## Highlights

- The built-in icon set grows from 3,467 to 6,810 logos: a full-color pack of service logos and
  a monochrome 2FA pack join the existing badge pack.
- The icon picker labels every icon and marks which pack it comes from.
- Settings → Icons → Browse icons opens a read-only library of every bundled icon, with search,
  a per-pack filter, and a large preview on tap.
- Codes animate when they roll over. Settings → Tokens → Code transition offers Dissolve (default),
  Roll, or Off, and the upcoming code fades in.
- With "Show next code" on, a hidden code now shows dots on both lines instead of dropping the
  second one.
- The token page's add button staggers its actions into place and turns its plus into a cross.

Install this build over 1.1.1; the vault and backup format is unchanged.

SHA-256 is published next to the APK.
