## Highlights

- Favourite is now a star in the detail header for both logins and tokens; the overflow menu keeps only edit and delete.
- Notes render as a full-height block that can be selected and copied by long-press, without a copy button.
- The notes field in the editor grows with its content instead of stopping at four lines.
- Detail page cards and section labels line up with the home and settings screens.
- The token detail page no longer repeats the "Notes" heading.
- Toggling a favourite updates the star immediately, with no feedback message.

Install this build over 1.1.0; the vault and backup format is unchanged.

SHA-256 is published next to the APK.
