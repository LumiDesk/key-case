# KeyCase · 设计决策 v0.5

> 2026-10-31 ｜ 状态：设计基线；实际 0.1.1 已按用户确认调整（无默认解锁方式、无分组、无令牌分组；仅手动检查更新使用网络）｜ 原型：`prototype/index.html`
> 本文取代 v0.4；`产品方案-v1.md`、`MVP技术方案-v2.md` 仅作历史记录。

## 1. 定位与技术栈

**KeyCase：Android 原生的本地密码管理器 + 动态令牌（TOTP）验证器。无账号、无云、无遥测；网络仅用于用户主动触发的 GitHub Release 更新检查。**

- 技术栈：**Kotlin + Jetpack Compose**
- 视觉：Material 3 组件与 color roles；原型只是 HTML 近似，不是最终实现

## 2. 解锁

- 解锁内容**垂直居中**，不再整体偏上
- 支持**默认解锁方式**：指纹 / 主密码，设置 → 安全 → 默认解锁方式（0.1.x 未实现，用户确认不做）
- 默认方式只决定优先展示哪一种；另一种仍可手动切换
- 正式 App 用 `BiometricPrompt` + Material 3 组件实现

## 3. 首页

- 顶部搜索框
- 四个统计块（2×2，约 92px 高）：全部密码、动态令牌、待处理、回收站
- “最近使用”五条（只显示名称/账号，不显示密码）
- 不再有“仅存储在此设备”“自动备份状态”“快捷操作”“换机提示”等大块提示

## 4. 列表与分组

- 密码/令牌列表**不再有“全部/收藏/分组”标签**，直接展示全部；保留搜索、A–Z
- 分组管理：设置 → 整理 → 分组管理
  - 新建、重命名、删除
  - 密码和动态令牌都计入分组
  - 删除分组时条目移到“未分组”

## 4.1 图标

- 图标加载失败或没有图标时，**用名称第一个字 + 背景色兜底**（参考 Aegis）
- 编辑条目时，修改图标入口在**顶部大图标右下角的编辑按钮**，不在表单底部
- 图标包里的图标只在能正常加载时显示；加载失败同样回落到首字

## 5. 动态令牌

- 列表默认直接显示验证码；可关闭
- 关闭后显示 `••• •••`；**点一下：原地显示 10 秒，同时立即复制**
- 验证码容器固定 94px，显示/隐藏不改变布局
- 倒计时：小圆环 + 剩余秒数；详情页细圆环 + 大码
- 数字分组：不分组 / 2 / 3 / 4 位，默认 3 位

## 6. 主题与深色模式

- 默认蓝色 `#2F6BFF`
- 设置 → 外观与图标 → 主题色：
  - 任意颜色选择器（系统取色器）
  - 手动输入 `#RRGGBB`
  - 5 个快捷预设
  - **恢复默认颜色**
- 深色模式：跟随系统 / 浅色 / 深色
- 自定义颜色会自动派生深/浅色调，深色模式下自动调整
- 正式 App 用 Material 3 的 tonal palette / dynamic color 实现同等效果

## 7. 安全设置

保留：自动锁定、生物识别、截屏保护。
**删除：剪贴板 60 秒清除。**

## 8. 图标包

- 内置包使用提供的 **`aegis-simple-icons-v269.zip`**（Aegis 格式：`pack.json` + `SVG/`，3467 个图标，v269）
- 内置包不可删除；导入的图标包可删除
- 支持导入同格式 ZIP；选中图标后复制缩小后的字节进加密容器
- 源文件：`assets/aegis-simple-icons-v269.zip`
