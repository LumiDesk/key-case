# 统一设计系统

KeyCase 的视觉语言：**克制、可信赖、信息优先**。单一主色 + 中性画布，所有表面都是不透明实色，
没有玻璃、模糊或渐变；动效只用于解释状态变化。

## 颜色令牌（`lib/app/app_theme.dart`）

| 角色 | 浅色 | 深色 |
|---|---|---|
| 画布 | `kcCanvasLight` `#F3F5F8` | `kcCanvasDark` `#101318` |
| 内容卡片 | `kcSurfaceLight` `#FFFFFF` | `kcCardSurfaceDark` `#1A1F27` |
| 浮动表面（弹层/菜单） | `kcSurfaceLight` | `kcSurfaceRaisedDark` `#232A35` |
| 主文字 | `kcInk` `#151922` | `#F0F3F8` |
| 细描边 | `kcLine` `#E1E8F1` | `white @ 12%` |
| 主色 | `kcAccent` `#2563EB` | 同色 |
| 危险 / 警告 / 成功 | `kcDanger` / `kcWarning` / `kcSuccess` | 同色 |

- 主色来源：跟随系统（内置蓝，随明暗切换深浅）、五套预设（蓝 / 青 / 绿 / 琥珀 / 玫红）、
  或 HSV 自定义色。
- 语义色在浅色底必须经 `kcSemantic(context, ...)` 取加深变体，否则对比度不足 4.5:1。

## 排版与间距

| 项目 | 约定 |
|---|---|
| 页面左右留白 | 以 16dp 为基准：`KcPage` 固定 2dp，页头/列表 14dp，卡片 12dp，分组标签 16dp |
| Header 高度 | 56dp（`KcHeader` / `KcSubHeader`） |
| 卡片 | 圆角 16、内边距横 14 / 纵 12、细描边 |
| 列表行 | 横 14 / 纵 9，图标 38dp，行间不画通栏分割线 |
| 圆角 | `kcRadiusSm` 8 / `kcRadiusMd` 12 / `kcRadiusLg` 16 / `kcRadiusXl` 24 |
| 页面最大宽度 | 440dp（平板/横屏居中） |

字号：页面标题 22/w800、区块标题 12/w700、正文 14、辅助 12、标签 10–11。
验证码使用等宽数字（`FontFeature.tabularFigures`），避免倒计时跳动。

## 表面材质

- 卡片、导航、菜单、弹层全部不透明实色；层级靠**表面色差 + 描边**表达。
- 页面背景是单一纯色，不铺渐变。
- 动效只用于状态变化：弹层滑入/滑出、轻反馈淡入/上移、进度与开关过渡；不做模糊、渐变或
  装饰性动画。

## 组件规范

- **页面头**：标题 + 数量/状态副标题内联；搜索、排序用 24dp 图标按钮。
- **列表**：按首字母分组，组头字母 + 细分隔线；令牌行右侧是验证码胶囊 + 倒计时环。
- **验证码**：列表里藏在胶囊中、点击复制；关闭“显示验证码”时显示圆点，详情页点击后临时
  显示 10 秒。
- **详情**：左侧字段名 92dp 固定列，右侧值可点复制；网址整行可点打开浏览器。
- **设置**：分组标签在卡片外，卡片内是 `KcSettingsRow` / `KcSwitchRow`，分隔线缩进到图标下方。
- **空状态**：88dp 圆形图标 + 标题 + 说明 + 可选主操作。
- **轻反馈**：底部胶囊，1.6 秒自动消失；破坏性确认走对话框，不用轻反馈。

## 验收

- 393×852 为基准尺寸，另测 360dp 窄屏与最大字号。
- 浅色/深色两套都要看；语义色对比度 ≥ 4.5:1。
- 列表滚动、键盘弹起、返回手势、系统返回键都要在模拟器上过一遍。
